# Задачи Neighborhood Fixer P0

Все игровые критерии относятся к [GDD v0.7](../Roblox_Neighborhood_Fixer_GDD_TZ_v0.7.md).
`[x]` означает проверенный результат, а не написанный файл.

- [x] **ENV-02: размер окна.** Обычный режим Studio вместо фиксированного
  виртуального рабочего стола Wine. Внешнее окно и viewport Studio согласованы
  после двух изменений размеров; изменение рабочего разрешения подстраивает
  окно; 96 DPI и обход чёрного квадрата сохранены. Проверка: runtime-геометрия
  и снимки. Файлы: только desktop helper, конфигурация, его тесты.
  Факт: 1920×1080 → 1280×720 → 1920×1080, окно 1904×995 → 1264×635 →
  1904×995 без ручной подгонки. Пользовательская служба включена.
- [x] **ENV-01: свежий runtime.** MCP читает текущую сцену, запускает/останавливает
  Play и читает Output; Rojo передаёт пробный Source и его восстановление.
  Проверка: фактический отчёт в `docs/ENVIRONMENT.md`.
  Факт 3 ноября: исправлена активная папка Studio-плагина, Rojo 7.7.1 загружен.
  Пробный Source из VS Code/диска пришёл в Edit, затем исходный текст восстановлен
  и побайтно сравнен. MCP проверил Edit/Server/Client, Play/Stop и Output.
- [x] **CORE-01: исходная база.** Воспроизводимые инструменты, Rojo, strict,
  тесты, CI созданы и проверены ранее; ветка реализации создана.
- [x] **DATA-01a: контракт профиля и доллары.** Изолированные новые профили,
  сериализуемые данные, миграция, отказ повреждённой/будущей схемы, одно
  завершение работы → одна выплата, одна покупка → один экземпляр. Проверка:
  standalone Luau; успех, отказ, границы, повтор, независимость игроков.
  Факт: 11 тестов Profile + 8 Economy; контракты подключены к runtime.
  DATA-01 целиком и настоящие облачные сохранения остаются незавершёнными.
- [x] **DATA-01b: владение сессией и запись.** Ошибка загрузки не даёт
  редактируемый дефолт; чужая/просроченная сессия и старая ревизия не пишут;
  повтор после неизвестного исхода не дублирует результат. Проверка: тесты
  настоящей логики на детерминированном адаптере, strict, сборка.
  Факт: 15 тестов координатора; Roblox UpdateAsync adapter подключён. Настоящая
  облачная запись остаётся в SAVE-01, не подменяется MemoryPreview.
- [ ] **WORLD-01a / UX-01a: первый вход.** Реальные профиль и приватная комната,
  HUD долларов и состояние ошибки загрузки; EN/RU. Зависит от DATA-01.
  Факт: профиль, комната, $0, Home/возврат, EN→RU подтверждены в Play.
  Поздняя загрузка/respawn при сохранении — 2 standalone lifecycle-регрессии.
  Факт: реальный respawn тоже подтверждён. Mobile emulator проверил HUD/Home,
  EN/RU и свободные зоны джойстика/прыжка. Два игрока и реальное устройство
  ещё требуют отдельной проверки; весь WORLD/UX ticket пока не закрыт.
- [x] **WORLD-01b: маршрут.** Улица, входы, клиентская комната и магазин
  достижимы пешком. Зависит от WORLD-01a. Проверка: пройти маршрут в Play.
  Факт: первый игрок физически прошёл home → client → shop через Humanoid.MoveTo
  с проверкой достижения каждой точки, без телепортов на маршруте. Home UI
  затем вернул его в свою комнату. Это автоматизированная проверка ходьбы.
- [ ] **UX-01b: Jobs и Map.** Сервер выдаёт реальный jobId, карта и указатель

  Проверка: EN/RU, принятие и отмена заказа на ПК/mobile.
  Реализованы реальные Jobs/Map, jobId, клиентская комната, контрастная стрелка,
  метка стены и контекстная кнопка следующего этапа. Принятие/этапы/приёмка
  подтверждены Touch в эмуляторе. Мобильная отмена проверена дважды: $0,
  новый jobId, старая отмена не затрагивает новый заказ. Визуальный обход Map
  в эмуляторе завершён: исправлено обрезание, разные формы меток, EN/RU,
  portrait/landscape/низкий экран, Touch «К цели» → HUD, обновление метки при
  ходьбе, серверное прибытие, очистка цели после отмены. Реальное устройство
  остаётся в QA. Подробности: docs/NAVIGATION.md.

  неверный цвет исправим; камера всегда восстанавливается.

  Факт PC Play: этапы/исправимый цвет, выход и восстановление камеры после
  приёмки/смерти подтверждены. Прибытие учитывает серверный LOS.
  Touch Play выявил задержку до CharacterRemoving; исправление Died подтвердило
