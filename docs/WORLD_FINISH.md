# Подтверждённая покраска в комнате

После Review стена сохраняет подтверждённое покрытие и серые пропуски.
Переход ко второй стене Duo сохраняет первую. После сдачи источник —
`job.finish` с соответствующей Reward-квитанцией, включая восстановленный
профиль. Старая квитанция без finish сохраняет прежний сплошной цвет без
выдуманной маски. Новый заказ, отказ, недоступность очищают оформление.

`PaintWallFinish` подключён к существующему `JobService.send`. Он читает
серверный work/профиль, не меняет покрытие, деньги, XP или право сдачи.
Пока текущая стена красится, работает прежний плавный локальный renderer.
Мировой результат появляется только у проверенных completedMasks/текущей Ready.

Используется `PaintFinish.preview` с максимумом 12×8. Большая сетка уменьшается
консервативно: смешанная клетка остаётся пропуском. Основной цвет задаёт Part,
SurfaceGui показывает только клетки меньшинства: ≤48 Frames + одна Gui на
стену, ≤98 объектов для двух стен, без физических деталей. Идеальная стена
обходится цветом Part без Gui. Sync переиспользует маску/клетки; новых подписок
и кадровых циклов нет. Удаление комнаты не оставляет модели.

Мировой слой: Face=Back, FixedSize, LightInfluence=1, MaxDistance=140,
ZOffset=0. LocalPaint.ZOffset=1 сохраняет приоритет рабочего рисунка.
ZOffset задаёт порядок SurfaceGui, не перемещает геометрию:
[Roblox SurfaceGui](https://create.roblox.com/docs/reference/engine/classes/SurfaceGui).

`PaintWallFinish.test.py` исполняет настоящий renderer: Ready/две стены,
Profile.decode, legacy/неверная квитанция/маска, cache/лимит объектов,
недоступность/отказ/удаление. Исполняется настоящий блок создания LocalPaint.
PaintWorksiteAdapter проверяет контекст до Snapshot. Мутации Ready и ZOffset
тесты обнаруживают. Полный check/обе сборки прошли.

Native solo MemoryPreview: Tutorial → Mint → Rose, ввод мышью дал 84/96.
Все 12 пропусков подтверждены на клиентской мировой стене после Review,
оплаты и sync; маска равна сохранённому finish, Gui не пересоздалась.
Rose дал $350 без чаевых, итог $900/210 XP/шесть пакетов. После Stop —
90 Source совпали с канонической сборкой и чистый Edit.
