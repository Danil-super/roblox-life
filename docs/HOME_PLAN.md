# Домашний этап: план комнаты

Продолжает §1.2/§27 ТЗ: заработок даёт видимое обустройство бесплатной комнаты.
Это локальный этап P0; новые профессии/полный город не добавляются до gate P0.

План добровольный. Три цели: растение; кресло/столик/торшер для чтения;
книжный шкаф. Всего пять разных предметов. Покупка сама по себе цель не закрывает:
нужно установить экземпляр. Дубликаты не заменяют отсутствующий тип мебели.
Если убрать предмет на склад, текущий план снова показывает незаконченный пункт.
Это состояние комнаты, а не пожизненное достижение; награды за перестановки нет.

В каждой цели также показаны стоимость недостающих покупок и дефицит до
набора. Склад вычитается из покупок; при нехватке средств и отсутствии
готовой к установке мебели можно открыть заказы кнопкой поиска работы.
Это отдельный выбор без принятия заказа: [HOME_BUDGET.md](HOME_BUDGET.md).

Кресло и книжный шкаф — собственные модели из Roblox-примитивов, модель v1.
Цены $320/$280 — тестовые гипотезы. Старые цены/ID/версии не меняются, формат
профиля прежний. План выводится из подтверждённых inventory/placements, отдельный
флаг выполнения и новый платёжный API не нужны. Шкаф занимает 4×1,5×6 studs,
кресло 4×4×3,8; серверный валидатор сохраняет проходы и проверку пересечений.

Кресло содержит штатный Seat. В фабрике он выключен: витрина/миниатюра/ghost
не усаживают игрока. Только серверная установленная модель включает сиденье.
Встать можно прыжком. Прогресс не зависит от сидения и не влияет на выплаты.

HomePlan.test проверяет пустой план, покупку без установки, дубликаты, удаление
со склада/из комнаты, отсутствие мутации/перетекания между игроками, decode
новых товаров и серверный отказ загромождению двери. Факты Studio и ограничения
нужно отдельно записать в ENVIRONMENT.md после настоящей проверки.


ДОМ → План комнаты. Карточки показывают купленные/установленные предметы,
завершённые цели подписаны «Готово». Нажатие отсутствующего предмета открывает
магазин и прокручивает к нему; купленного — склад с нужным экземпляром.
Кнопка возврата закреплена под прокручиваемым содержимым. EN/RU вынесены в Strings.

В кресле используется штатная [Seat](https://create.roblox.com/docs/reference/engine/classes/Seat).
Нативная физика в Play воспроизвела откат персонажа к прежнему сиденью через
0,3 с после мгновенного unseat/PivotTo. Разрыв SeatWeld оказался недостаточным.
После освобождения проверяется возможность смены владельца физики, сервер
удерживает персонажа 1 с, затем возвращает automatic ownership. Опора API:
[BasePart](https://create.roblox.com/docs/reference/engine/classes/BasePart).
При невозможности безопасно освободить assembly возврат отклоняется. Guard
отложенного восстановления не обращается к удалённому персонажу. Этот код
не меняет позу или владение мебелью и не выдаёт награды.

HomePlan.test выполняет также настоящий memory ProfileStore: полный план,
release/reload, $700 после покупок включая дубликат растения, повтор покупки
кресла без нового экземпляра/списания. Это не облачный перезаход.
HomePlannerUI.test исполняет переходы к магазину/экземпляру и отказ без
подтверждённого профиля. SeatReturn.test проверяет порядок detach/ownership/move,
восстановление auto и исчезнувший/мёртвый/непригодный assembly. Физика сиденья
доказывается отдельным настоящим Play, а не этими заглушками.


## Добровольное продолжение после 5/5

Базовые три цели и пять предметов остаются прежними. После их установки
HomePlan.displayGoals добавляет карточку «Отдых и творчество»: диван, мольберт,
ящик с растениями. Это дополнительный выбор; исходный план 5/5 и его Jobs
не требуют восьми покупок. Владение без установки не завершает цель; склад
снимает текущую готовность, повторная установка не требует покупки.

Механика и проверки: [CREATIVE_HOME.md](CREATIVE_HOME.md).
