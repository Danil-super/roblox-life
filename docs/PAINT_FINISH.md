# Подтверждённое качество покраски

PAINT-RESULT-11 добавляет добровольную цель мастерства из §5.3/§5.7/§26.6.
Сдать работу можно при прежнем допустимом покрытии. Отличный финиш требует
не менее 95% каждой стены, идеальный — полного покрытия каждой стены.
95% — гипотеза P0 в `PaintConfig.finishExcellentPercent`. Оплата, XP,
доступ к инструментам и отсутствие штрафа за обычные ошибки не меняются.

Оценка использует худшую стену. Например, 100% + 80% дают 80%, а не среднее
90%. Клиентская анимация не улучшает результат. Цвет, подготовка, длительность,
реальные мазки и явная серверная приёмка остаются прежними условиями.

## Сохранение и совместимость

Текущая схема профиля — **3**. У завершённой покраски `jobs.active.finish`
может содержать `{columns, rows, masks}`: одну или две бинарные маски сервера.
Размеры — целые 1…64, строки — ровно columns×rows символов 0/1. Парсер
копирует массив без метаметодов, запрещает разрывы/чужие ключи/лишние стены,
незавершённую работу с finish и несогласованное число стен известного шаблона.
Экономическая квитанция и журнал операций сохраняют прежний контракт.

`Painting.finish` принимает только все проверенные стены с допустимыми
масками. `Jobs.submit` записывает finish после успешной Economy в том же
кандидате ProfileStore, без yield. Ошибка выдачи награды не добавляет finish.
Повтор Completed возвращает прежнюю квитанцию и не заменяет сохранённые маски.
Клиент не передаёт ни finish, ни оценку, ни дополнительную сумму награды.

Схемы **1 и 2** читаются и мигрируют в 3 с сохранением денег, XP, собственности,
поз и истории обучения. Отсутствующая старая маска остаётся неизвестной:
старый результат подтверждает оплату, но не получает выдуманные 100%/оценку.
Schema 2 с новыми finish-полями и будущая неизвестная версия отклоняются.
Старый сервер, понимающий только schema 1/2, не сможет читать запись schema 3;
откат требует совместимого читателя. Облачная миграция здесь не заявляется:
проект работает локально, Studio использует MemoryPreview.

`JobResult.read` выдаёт копию finish только вместе с действительной квитанцией
Completed текущего заказа. Оценка вычисляется из сохранённых измерений по
текущему параметру P0. Это результат последнего активного завершённого заказа,
а не новый архив всех работ: после принятия следующего заказа прежний active
заменяется, как и раньше. Новых наград/балансов или публичного рейтинга нет.

## Проверки

`PaintFinish` проверяет границы 94/95/100%, худшую стену, порядок стен,
неизвестные/некорректные данные и ограниченное уменьшение маски без скрытия дыр.
`PaintFinishPersistence` исполняет реальные Jobs/Painting/Economy/ProfileStore:
77/96 оплачиваются прежней суммой, повтор не пересчитывает маску, копии
независимы, corrupt не загружается. Schema 2 с купленным и установленным
предметом мигрирует, сохраняя $70/50 XP/позу 345°. Неопределённая запись не
выдаёт доступный профиль; тот же intent/retry/release/reload сохраняет исходные
77 клеток и одну выплату, даже если runtime-маска уже изменилась.

Полный `bash scripts/dev.sh check` прошёл. Облачный rejoin и многоклиентская
приёмка остаются отдельными gate. Визуализация не меняет эти правила.
