# Где находятся файлы проекта

Основной каталог: `/home/danil/Рабочий стол/roblox-life`.
Именно его нужно открывать в VS Code. Git, исходники и ТЗ уже находились здесь;
переносить или заново клонировать репозиторий не требуется.

| Каталог / файл | Содержимое |
| --- | --- |
| `src/`, `tests/` | Исходники Luau и проверки |
| `default.project.json`, `prototype.project.json` | Текущая игра и старый отдельный прототип |
| `Roblox_Neighborhood_Fixer_GDD_TZ_v0.7.md` | Исходное ТЗ |
| `tasks/`, `docs/`, `README.md`, `AGENTS.md` | План, факты проверок и инструкции |
| `scripts/`, `.github/`, `.vscode/` | Инструменты разработки, CI и редактор |
| `.git/` | Полная локальная история Git |
| `.tools/` | Бинарники, определения типов, загрузки и локальные QA-отчёты |
| `build/roblox-life.rbxlx` | Свежая собираемая сцена игры |
| `build/sink-prototype.rbxlx` | Отдельный старый прототип |
| `backups/studio-scenes/` | Проверенные копии прежних контрольных сцен из кэша Vinegar |
| `backups/environment/` | Копия установленной службы подстройки окна |
| `backups/project-files-manifest.json` | Размеры и SHA-256 собранных снимков сцен |
| `graphify-out/`, `.codegraph/` | Локальные индексы текущего проекта |

3 ноября 2026 года в `backups/studio-scenes/` скопированы все девять файлов
из проектной папки `roblox-life-check` в кэше Vinegar: сцены, маленький Luau-probe
и архивные lock-файлы. Байты копий проверены SHA-256. Lock-файлы не нужно
восстанавливать или открывать как сцены. Копии не заменяют исходники `src/`.

Активная Studio пока использует временную сцену в своём кэше. Её исходный файл
сохранён на месте, чтобы не нарушать открытое окно. Это рабочая копия, а не
единственное место хранения данных проекта. Дальше открывать из корня проекта
`build/roblox-life.rbxlx`, подключать Rojo к `127.0.0.1:34872` и менять код в VS Code.
После изменения кода перед автономным открытием сцены выполнить:

```bash
bash scripts/dev.sh build
```

`build`, `.tools`, `backups`, индексы и runtime-данные исключены из Git.
Они находятся внутри каталога на диске, но не отправляются на GitHub.

Vinegar/Flatpak, Wine-префикс, установленный Studio-плагин, авторизация Codex,
расширения VS Code и системные службы сохраняют штатные каталоги пользователя.
Это установленные приложения и пользовательские настройки. Перенос их рабочих
каталогов внутрь репозитория сломал бы стандартные пути и смешал бы авторизацию
с файлами игры. Проектный код launcher/helper уже находится в `scripts/`;
проверенная загрузка `Rojo.rbxm` — в `.tools/downloads/`.
