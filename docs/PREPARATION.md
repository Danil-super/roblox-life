# Снятие старой отделки

По решению пользователя от 11 ноября приоритет — игровой процесс. Отдельная
матрица устройств отложена; серверные границы, локальные проверки и проверка
нового действия в одиночной Studio сохраняются.

Начиная с «Розовой спальни» (120 XP), подготовка состоит из двух действий:

1. Подойти к стене, посмотреть на коричневый участок и удержать E у нативной
   подсказки «Очистить шпателем». На Touch предусмотрена родная кнопка prompt.
   Очистить все три участка: они исчезают по одному, HUD подтверждает 0–3.
2. Нажать прежнюю кнопку укрытия пола, затем выбрать инструмент/краску.

Tutorial и Mint сохраняют короткую подготовку. Требование задаёт сервер по
контракту (minXP ≥120), а не текущий клиентский XP. У двухстенных заказов
очистка общая: вторую стену красят после прежней смены поверхности.

В Jobs до завершения очистки показан счётчик, кнопка укрытия неактивна;
жёлтая кнопка HUD открывает план подготовки. Право продолжить сервер проверяет
независимо. За очистку не начисляются деньги/XP; платят только за сданную
покраску. Цены, награды и профиль schema3 прежние.

Painting хранит три runtime-флага и один текущий участок/серверное время.
HoldDuration UI =0,8 с; сервер принимает завершение через 0,6–4 с от начала.
Проверки начала/завершения: владелец, профиль/активная работа, текущий живой
персонаж, phase/work, дистанция до стены и участка (≤8), LOS. Новый персонаж
не продолжает старое удержание. Повтор уже снятого участка ничего не меняет.
Параллельные удержания не завершают несколько участков одновременно.

PaintPreparation — три статичных Part и три native prompt в одной Folder.
Нет collide/query/touch/shadow, новых remotes, внешних ассетов или циклов.
Sync сохраняет модель; защита пола/недоступность/отмена/новый work удаляют её.
Клиент локализует подсказки и скрывает их под меню; Cleared/Owner приходят
с сервера. Destroy/удаление снимают подписки. Нативные события сами по себе
не доказывают право на прогресс. После смерти/перезапуска очистка начинается
заново вместе с незавершённой покраской, как и прежняя runtime-маска.

Действие шпателем пока представлено удержанием и изменением стены;
отдельной анимированной модели шпателя нет. Это игровой прототип подготовки,
не новая самостоятельная профессия ремонта.

Проверки: Preparation.test.luau, реальная фабрика/hold callbacks в
PaintPreparationScene.test.py, реальные подсказки/cleanup в
PreparationPrompts.test.py; TravelUI/ContractText и адаптер восстановления
проверяют подключение к существующему потоку. Полный check обязателен.
Факты нативной проверки: [ENVIRONMENT.md](ENVIRONMENT.md).

11 ноября пройдены полный check и один полный PC-путь в MemoryPreview:
Tutorial → Mint → Rose, три настоящих удержания E → укрытие → покраска →
сдача. Итог $900/210 XP, три заказа, шесть уникальных пакетов профиля;
очистка сама не платила. Source 87/87 и чистый Edit подтверждены.
Физический Touch, облачное сохранение и несколько игроков не проверялись.

API сверены через Context7 по официальным
[ProximityPrompt](https://create.roblox.com/docs/reference/engine/classes/ProximityPrompt)
и [ProximityPromptService](https://create.roblox.com/docs/reference/engine/classes/ProximityPromptService).
